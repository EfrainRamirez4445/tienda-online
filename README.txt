DESCRIPCIÓN
Sitio web de una tienda online que vende camisas, joyería, perfumes y tenis.
Incluye página de inicio y 10 páginas subordinadas: camisas, joyería,
perfumes, tenis, contacto, nosotros, ofertas, envíos, preguntas y carrito.

ESTRUCTURA HTML5
- Uso de etiquetas semánticas: header, nav, main, section, article, aside, footer.
- Página de inicio (index.html) con carrusel, categorías y ofertas.

DISEÑO CSS
- Bootstrap 5 para la cuadrícula, el menú y los botones.
- Estilos personalizados en css/styles.css (colores, tarjetas, carrusel).
- Diseño responsivo para móviles, tabletas y escritorios.

JAVASCRIPT (js/script.js)
- Carrusel de imágenes con botones y cambio automático.
- Resaltado de productos al pasar el ratón y detalles al hacer clic.
- Validación del formulario de contacto en tiempo real.

BUENAS PRÁCTICAS
- Código ordenado, comentado y organizado en carpetas (css, js, images, pages).
- Nombres de archivo en minúsculas y sin espacios.
- Texto alternativo (alt) en las imágenes.
